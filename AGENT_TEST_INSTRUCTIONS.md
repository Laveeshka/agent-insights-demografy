# SQL Agent Test Instructions

These instructions test the SQL agent directly in the terminal. No Streamlit frontend is required.

## 1. Open The Project

Open PowerShell and run:

```powershell
cd D:\agent-insights-demografy
```

## 2. Create And Activate A Virtual Environment

If `.venv` does not already exist:

```powershell
py -m venv .venv
```

Activate it:

```powershell
.\.venv\Scripts\Activate.ps1
```

The prompt should begin with `(.venv)`.

## 3. Install Dependencies

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
pip install python-dotenv
```

## 4. Configure Private Credentials

Create a local `.env` file at:

```text
D:\agent-insights-demografy\.env
```

Use your own credentials. Do not copy somebody else's API key or service-account key.

The file should contain:

```text
GEMINI_API_KEY=your-gemini-api-key
BIGQUERY_PROJECT=demografy
GOOGLE_APPLICATION_CREDENTIALS=D:\path\to\your-service-account.json
```

The service-account JSON file should be stored outside the repository. Never commit it or share its contents.

## 5. Check The Credentials File

Replace the example path with the path in your `.env` file:

```powershell
Test-Path "D:\path\to\your-service-account.json"
```

Expected output:

```text
True
```

## 6. Load And Check The Environment

```powershell
python -c "from dotenv import load_dotenv; import os; load_dotenv(r'D:\agent-insights-demografy\.env'); print('Gemini key loaded' if os.getenv('GEMINI_API_KEY') else 'Gemini key missing'); print('Project:', os.getenv('BIGQUERY_PROJECT')); print('Credentials path loaded' if os.getenv('GOOGLE_APPLICATION_CREDENTIALS') else 'Credentials path missing')"
```

Expected output:

```text
Gemini key loaded
Project: demografy
Credentials path loaded
```

Never print the actual API key or the contents of the JSON file.

## 7. Test BigQuery Access

```powershell
python -c "from dotenv import load_dotenv; load_dotenv(r'D:\agent-insights-demografy\.env'); from db.bigquery_client import BigQueryClient; client = BigQueryClient(); print('Project:', client.project); print(client.query('SELECT 1 AS connection_test'))"
```

Expected output should show:

```text
Project: demografy
```

and a returned value of `1`.

## 8. Check The Gemini Model

```powershell
Select-String -Path agent\sql_agent.py -Pattern "model="
```

The configured model must be available to the Gemini API key being used. If the API reports that the model is unavailable, update the model name to one available in Google AI Studio.

## 9. Disable Optional LangSmith Tracing

These variables prevent unrelated LangSmith telemetry errors during testing:

```powershell
$env:LANGCHAIN_TRACING_V2 = "false"
```

```powershell
$env:LANGSMITH_TRACING = "false"
```

## 10. Run The SQL Agent

Run:

```powershell
python -c "from dotenv import load_dotenv; load_dotenv(r'D:\agent-insights-demografy\.env'); from db.bigquery_client import BigQueryClient; from agent.sql_agent import create_demografy_agent; client = BigQueryClient(); agent = create_demografy_agent(client); result = agent.answer_question('What are the top 5 suburbs by prosperity score?'); print('--- SQL ---'); print(result['sql']); print('--- ROWS ---'); print(result['rows']); print('--- ANSWER ---'); print(result['answer']); print('--- ERROR ---'); print(result['error'])"
```

## 11. Expected Successful Result

The output should contain:

```text
--- SQL ---
SELECT ...

--- ROWS ---
...

--- ANSWER ---
...

--- ERROR ---
None
```

The SQL is generated by Gemini, executed by BigQuery, and then used to create the natural-language answer.

## 12. Try More Questions

Try these questions one at a time:

```text
Which states have the highest diversity index?
```

```text
Which suburbs have the highest education or learning level?
```

```text
Which areas have the highest home ownership?
```

```text
Which suburbs have the highest rental access?
```

## 13. Test Conversation References

Ask:

```text
Which suburb has the highest prosperity score?
```

Then ask:

```text
What is its diversity index?
```

The current SQL agent processes each question independently. It does not yet remember previous questions or answers, so words such as `it`, `its`, and `them` may not resolve correctly.

## 14. What To Report

Please report:

- Whether the imports worked.
- Whether the BigQuery connection test worked.
- The generated SQL.
- Whether rows were returned.
- The natural-language answer.
- Any value shown under `--- ERROR ---`.

Do not send API keys, service-account JSON content, or private credentials when reporting results.

## Common Errors

### Gemini API key missing

Check that `GEMINI_API_KEY` exists in `.env` and that `load_dotenv(...)` points to the correct file.

### BigQuery credentials not found

Check that `GOOGLE_APPLICATION_CREDENTIALS` points to an existing JSON file and that the service account has permission to run BigQuery jobs and read the approved table.

### Model not found

The configured Gemini model is unavailable to the API key. Select an available model and update the `model=` value in `agent/sql_agent.py`.

### SQL generation failed

Check the error text. If the error refers to Gemini, resolve the model or API-key problem first. If it refers to BigQuery, check the generated SQL and the service-account permissions.
